## Descripción

* **Como** usuario administrador / super administrador
* **Necesito** editar información como el nombre o la descripción de alguno de los módulos con los cuales estoy interactuando
* **Para** actualizar los campos requeridos con el fin de tener la información de los ítems actualizada

---

## Criterios de Aceptación

* [ ] El nombre del ítem no puede quedar vacío.
* [ ] La descripción es opcional.
* [ ] La información se actualiza correctamente.
* [ ] Puedo visualizar un mensaje de éxito indicando que el recurso ha sido modificado exitosamente.
